# 字段与规则

## 输入与采信

每个样例有 JSON 契约和一组 CSV 图档。契约登记图批、晶圆设计参数、来源方向及声明记录数，也可带独立的片级交接台账。处理上限为每批 8 档、8 片、原始 CSV 合计 2 MiB，每档声明上限 12,000 条数据。读取先尝试 UTF-8 并去 BOM，再回退 GB18030。CSV 使用严格引号解析，以逻辑记录为单位保留物理起止行。

| CSV 字段 | 别名 | 类型与规则 |
|---|---|---|
| `wafer` | 片号 | 字符串，去首尾空格后匹配登记片号 |
| `x`, `y` | 列、行 | 原始整数格位，数字允许全角与正负号 |
| `attempt` | 测次 | 1–999 的序号，数值排序 |
| `result` | 判定 | `PASS/P/通过` 或 `FAIL/F/失败`，英文字母忽略大小写 |
| `bin` | 分档 | 通过为 1，失败为 2–999 |
| `note` | 备注 | 原始文本，可含逗号与换行 |

档头可换序。同档再次出现完整档头会新开一段，随后的数据使用该段列映射。每档第一张有效档头从记录账中扣除。重复档头、空记录和坏栏保留起止行与原始字段。CSV 断裂、档头不完整、声明条数不符会拒绝整个输入，空档、全空行、仅档头分别报码。

## 坐标与物理掩模

`origin_x/origin_y` 为机台原点。先扣原点，再应用 `x_left/y_down` 将局部轴转为右上为正。`notch` 是此时局部坐标的方向，取 `N/E/S/W`。设 `mirror` 为真时同时反射坐标和缺口向量的 X 分量。最后逆时针旋转 0/90/180/270 度，让缺口向量到达 `(0,-1)`。缺口最终朝南，显示顺序从北到南。

`radius` 为圆片半径，阵列每轴含 `[-radius, radius]` 的整数。先排出阵列外，再排半径外。`notch_depth > 0` 时，`y <= -radius + notch_depth` 且 `|x| <= notch_half_width` 的圆内点为空位，边界包含在内。圆内其余位置按有效半径 `radius - edge` 分类，落在圆周等式上的中心点有效。芯粒位置的几何单位为格，无效位产生隔离证据。

## 复测与簇

空串、`-`、`N/A`、`NULL`、`未知` 都表示缺少测值。坏测次、空值、坏结果、坏分档分别隔离，随后才比较有效测次。芯粒键为晶圆 + 标准坐标，测次键再增加测次。键相同时比较 `(result, bin)`，一致的行以文件名和物理行号选出一条采信，其余记重复。测值不同则同组所有行隔离。最大有效测次给出最终状态，冲突参与排序，缺测行不参与。早期冲突进入测次链，较新有效测次仍可裁决；没有有效测次则待测。

簇由最终 `FAIL` 芯粒沿上、下、左、右连接，同片计算。簇号按成员中最北、再最西的位置顺序生成。每簇带包围盒、成员、最终分档分布与证据行。冲突、待测和复测转通过的点都会阻断邻接。

## 核验与归档

- `valid = passed + failed + pending + conflict`，另以有效位坐标集合对照裁决键，报告缺位和多位。
- `yield_pct = passed / valid × 100`。覆盖率的分子为通过、失败、冲突。均用 Decimal 四舍五入到百分比两位，API 返回字符串，分母为 0 时返回 `null`。
- 实收记录等于采信、隔离、重复、空记录与重复档头之和。声明数据只包含采信、隔离、重复。复测历史中的有效记录计入采信账，同一芯粒的最终结果只进入阵列账一次。
- 实际阵列减交接台账给出差值。漏登片号、多余片号和数值差分别报告。台账差异可与阵列守恒同时成立。
- `run_id` 由规则版本、契约 SHA-256 和每个来源的字节数及 SHA-256 生成。归档保留规则版本、UTC 生成时间、计算耗时、输入摘要与结果摘要。
- 运行归档一次提交清单、结果和原始输入，批次键唯一。证据 JSON 附带原档的 Base64 编码、契约、隔离行、归并和对账结果。摘要采用 UTF-8 JSON，键排序，分隔符为逗号和冒号且无多余空格，保留非 ASCII 字符。

## 放行更正

迟到复测以标准坐标登记，字段与 CSV 测值同规则：测次 1–999，判定接受同样的别名并归一化为 `PASS/FAIL`，分档须与判定一致（通过为 1，失败为 2–999）。目标必须是该片有效芯粒，测次须新于测次链中已有的最大测次；同批记录按晶圆、坐标、测次排序，完全相同的记录只计一次，同芯粒同测次的不同取值拒绝整批。

- 更正只追加新版本：原图批的快照、台账对账与测次链不被改写，发布前会核验基批规则版本与结果摘要，归档被篡改或规则过旧时拒绝更正。
- `correction_id` 由更正规则版本、运行号和规范化后的迟到记录生成，内容相同即同版。重复发布返回原版本（HTTP 200 且 `reused` 为真），首次发布为 HTTP 201。发布写入单表单事务，失败时旧版本与基批保持不变。
- 更正文档逐枚记录变更芯粒的前后裁决、放行处置（`PASS` 为可放行 `RELEASABLE`，失败、待测、冲突均为须扣下 `HELD`）与完整测次链（迟到记录带 `late` 标记追加在链尾），并按片给出前后计数、交接差额前后值、可放行与须扣下清单及批次汇总。预览接口生成同一份文档但不落库。

## 原因码

| 阶段 | 状态或原因码 |
|---|---|
| 采信 | `BLANK_ROW` 空记录、`REPEATED_HEADER` 分段档头、`COLUMN_COUNT` 栏数不符 |
| 对表 | `UNKNOWN_WAFER` 未登记片号、`BAD_COORDINATE` 非法坐标 |
| 掩模 | `OUT_OF_GRID` 阵列外、`OUTSIDE_DISC` 圆片外、`EDGE_EXCLUSION` 边缘带、`NOTCH_VOID` 缺口空位 |
| 裁决 | `BAD_ATTEMPT` 测次无效、`NO_RESULT` 空测、`BAD_RESULT` 判定无效、`BAD_BIN` 分档不符、`SAME_ATTEMPT_CONFLICT` 同次矛盾、`DUPLICATE_RESULT` 同次同值 |
| 更正 | `CORRECTION_UNKNOWN_WAFER` 晶圆不在本批、`CORRECTION_CELL_NOT_ACTIVE` 非有效芯粒、`CORRECTION_BAD_BIN` 分档与判定不符、`CORRECTION_STALE_ATTEMPT` 测次不新于现有、`CORRECTION_ATTEMPT_CONFLICT` 同测次已存在、`CORRECTION_NOT_FOUND` 更正版本未找到 |

## 已知范围

入口运行仓内登记的 CSV 样例。机台契约包括整格位移、轴向和直角旋转，物理掩模采用圆片中心点规则及矩形缺口。未接入厂内 MES、设备二进制档或自由形状掩模。
