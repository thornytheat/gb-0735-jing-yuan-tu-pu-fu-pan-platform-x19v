# 晶圆图谱复判台

封测厂良率工程师可把不同机台的探针图对齐到同一片晶圆，核查边缘空位和复测争议，再把阵列、台账差异及原始证据一同交接。

## 启动

```sh
docker compose up --build -d
```

页面在 `http://localhost:18424`，接口文档在 `/docs`，健康探针在 `/healthz`。SQLite 归档保存在 `wafer_records` 卷中。需要一个空的演示库时，可给 `docker compose` 指定新的项目名，或在本地执行时设置新的 `WAFER_DB` 路径。

Python 3.12 也可直接运行。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --port 18424
```

首启会归档混合样例。顶部的样例选择器可切换输入，**运行样例**处理所选输入，**重跑**校验当前归档的原始输入与结果，**导出证据**下载当前归档。选择截断探针图可验证失败反馈。图批复盘可打开任一历史运行。

## 复判入口

| 页面 | 检查动作 |
|---|---|
| 图档采信 | 按档检查编码、段和逻辑记录数，找重复档头与坏栏 |
| 坐标对表 | 输入机台坐标计算标准点，核查镜像、转角及来源行 |
| 有效芯粒 | 在晶圆图上点选芯粒，核对物理分类、测次链与原始行。可用方向键换格 |
| 复测裁决 | 查通过、失败、待测和冲突，回看同次冲突的每一行 |
| 缺陷簇 | 查看最终失败芯粒的四邻域归并结果，再定位到图上 |
| 良率勾稽 | 核对实际阵列与交接台账，按原因码查隔离行；登记迟到复测并发布放行更正 |
| 图批复盘 | 切换历史、核对输入与结果摘要、下载证据包 |

混合样例含 W-07 和 W-08 两片晶圆。W-07 的 `(2,3)` 在第 2 次转为通过，`(3,3)` 与 `(4,4)` 在第 2 次冲突。W-08 复判比台账多一枚通过，少一枚失败。晶圆和批次汇总的良率均以有效芯粒为分母。

## 放行更正

交接单签出后到达的迟到复测不改写原图批，而是在良率勾稽页登记为**放行更正**：先**预览影响**查看每枚变更芯粒的裁决与处置变化、各片可放行与须扣下清单及交接差额的前后变化，确认后再**发布更正**生成带内容标识的新版本。同一批更正重复发布只会复用原版本，不会产生第二版；发布失败时旧版本与原图批保持不变。更正文档记录基批结果摘要与每枚芯粒的完整测次链，原交接单、台账与测次链始终可按原运行号查回。

## 验证

```sh
python -m pytest -q
```

容器内可运行 `docker compose exec -T app pytest -q`。源码在 `app/`，契约样例在 `sample_data/`，业务测试在 `tests/`。输入和计算规则见 [字段与规则](docs/DATA-DICTIONARY.md)，模块和反例见 [深度登记](docs/DEPTH.md)。
